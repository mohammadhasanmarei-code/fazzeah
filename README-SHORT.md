# موقع فزعة - Next.js

مشروع تعليمي لموقع عضويات مع تكامل Telegram Bot.

## ⚠️ تحذير

هذا مشروع تجريبي للتعلم والتطوير. يجب استخدام بوابات دفع رسمية (مثل Stripe أو PayPal) في البيئة الإنتاجية.

## التثبيت

```bash
npm install
```

## الإعداد

1. انسخ `.env.example` إلى `.env.local`
2. أضف قيم Telegram الخاصة بك
3. شغل المشروع:

```bash
npm run dev
```
